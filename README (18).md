# Experiment 18 — Simple LAN using Cisco Packet Tracer

1. Place one 2960 switch and three PCs.
2. Connect each PC FastEthernet0 to a switch port using Copper Straight-Through.
3. Configure these addresses:

| Device | IPv4 address | Subnet mask |
|---|---|---|
| PC0 | 192.168.1.1 | 255.255.255.0 |
| PC1 | 192.168.1.2 | 255.255.255.0 |
| PC2 | 192.168.1.3 | 255.255.255.0 |

4. From PC0 Command Prompt run `ping 192.168.1.2` and `ping 192.168.1.3`.
5. Save the project as `simpleLAN.pkt`.

**Output evidence:** Add the `.pkt` file and screenshot of successful ping output if your course rules allow sharing them.
