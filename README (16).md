# Experiment 16 — RTP packet delay and loss using Wireshark

1. Start Wireshark on the interface carrying the RTP/VoIP stream.
2. Capture a real RTP stream or open a provided capture file.
3. Use **Telephony → RTP → RTP Streams**.
4. Select a stream and choose **Analyze**.
5. Record packet count, lost packets, maximum/mean jitter, and delta from the Analyze window.

**Output evidence:** Save screenshots of RTP Streams and Analyze statistics. If no RTP stream is present, do not invent metrics; capture a suitable session or use a provided lab capture.
